# MSc Health Data Science Placement Portfolio — Ikarians

This repository documents an MSc Health Data Science placement undertaken
with **Ikarians**, an early-stage digital health platform that combines
wearable data (primarily Garmin), a one-off onboarding questionnaire and a
daily in-app lifestyle survey, feeding an AI engine that generates
patient-facing insights and clinician-facing dashboard alerts.

The placement brief was explicit that the aim was not to build production
systems, but **to help Ikarians transform complex, multi-source health
data into meaningful, structured and actionable data for insight** — see
[`01-project-context/README.md`](01-project-context/README.md) for the
full framing.

## How this portfolio is organised

The repository is structured as a progression, with each stage building on
the findings of the last:

| Section | Stage | Question it answers |
|---|---|---|
| [`01-project-context/`](01-project-context/) | Familiarisation | What is Ikarians, and what evidence base informs this work? |
| [`02-health-data-mapping/`](02-health-data-mapping/) | Weeks 2–3 | What data exists, where does it come from, and how does it move through the system? |
| [`03-data-quality-and-value/`](03-data-quality-and-value/) | Weeks 4–5 | Is that data reliable, which parts carry genuine value, and what's missing? |
| [`04-ai-readiness/`](04-ai-readiness/) | Weeks 6–7 | What has to be true of a piece of data before an AI model should be trusted with it? |
| [`05-product-and-strategy/`](05-product-and-strategy/) | Week 9 | What concrete tools follow from all of the above? |
| [`06-supporting-evidence/`](06-supporting-evidence/) | — | The original, unmodified deliverables that this portfolio is built from |
| [`07-final-report/`](07-final-report/) | Closing summary | A single-document summary of the whole placement, findings and recommendations |



## Scope

The placement followed a 10-week framework (retained in full at
[`06-supporting-evidence/Ikarians_-_MSc_Health_Data_Science_Placement_Framework.pdf`](06-supporting-evidence/Ikarians_-_MSc_Health_Data_Science_Placement_Framework.pdf)),
covering familiarisation, data mapping, data quality assessment,
AI-readiness design, insight discovery, product recommendations and a
final roadmap.

While the core objectives were fully met, project deliverables evolved during the course of the placement.

- **Week 8 — Insight Discovery** was not completed as a standalone stage.
  The insight-generation questions it would have covered were instead
  folded into the AI-readiness work in Section 04, particularly the
  [Health Summary Structure](04-ai-readiness/health-summary-structure.md).
- **Week 9- Product & Strategy**: Originally scoped for general dashboard recommendations,
  this deliverable was refined into three concrete, explainable tool specifications directly derived from data quality and readiness findings.
